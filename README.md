# RAG Eval Lab：可复现评测闭环

> 状态：开发中｜数据：100% 虚构公开示例，不含完美中国、客户、同事、内网或账号信息  
> 目标：用同一批文档、问题和配置，展示“基线 → 失败归因 → 改进 → 回归”的完整证据链。

## 边界

本项目评估检索、证据引用、无依据拒答和提示注入防护。为了让结果可复现，答案由确定性模板组装，**不伪称调用了 LLM**。后续可以接入真实生成模型，但必须保留数据版本、配置和原始结果。

## 外部视角验收

- [ ] 不安装第三方包的 Python 3 可执行 `python3 src/evaluate.py`，退出码 0，并生成基线/改进两份真实结果。
- [ ] 至少 16 条案例覆盖直接检索、多文档、无依据拒答、提示注入四类；逐题保留输入、期望、实际、证据和失败层级。
- [ ] 改进配置相对基线的提升来自真实检索/防护逻辑，不在结果文件硬编码通过率。
- [ ] 静态页面可通过普通 HTTP 服务打开，展示两种配置指标和失败案例。
- [ ] 全项目无密码、令牌、公司原文、客户数据、同事姓名和内网地址。
- [ ] 公共部署后，另一设备/无痕窗口可打开链接；部署前不宣称已有公开链接。

## 公开地址

- 页面：https://wanggaoxingnb-cyber.github.io/rag-eval-lab/
- 仓库：https://github.com/wanggaoxingnb-cyber/rag-eval-lab
- `docs/` 是 `web/` 的发布镜像；修改后运行 `python3 src/sync_docs.py`，不要只改其中一份。

## 当前真实结果

- 基线：**9/16（56.25%）**；多文档证据覆盖 1 例失败、无依据拒答 2 例失败、提示注入 4 例失败。
- 改进：**16/16（100%）**；仅表示本项目 16 条虚构案例全部通过，不能外推为企业系统整体准确率。
- 详细逐题结果见 `REPORT.md` 和 `web/results.json`。

## 复现

```bash
python3 src/evaluate.py
python3 src/sync_docs.py  # 重新评测并同步到 GitHub Pages 的 docs/
python3 -m http.server 8765 --directory web
# 打开 http://127.0.0.1:8765
```

## 目录

- `data/documents.json`：虚构制度文档，按章节组织。
- `data/eval_cases.json`：评测问题与期望行为。
- `src/rag.py`：BM25 检索、配置、答案组装和防护。
- `src/evaluate.py`：基线/改进执行、指标、归因和报告。
- `web/`：无需构建的静态展示页。
